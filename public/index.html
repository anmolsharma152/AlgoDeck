SuperMemo-2 Spaced Repetition

Never forget a pattern. AlgoDeck tracks your solution quality (q ∈ [0..5]) and calculates the exact date (I_n) you need to review each problem before memory decays.

I_n = I_{n-1} × EF'
EF' = EF + (0.1 - (5-q) × (0.08 + (5-q) × 0.02))

Chess-Style ELO Rating Engine

Track your coding proficiency with real-time ELO updates. Solve harder problems (Medium/Hard) to boost your rating (R_user) using expected probability functions.

E_A = 1 / (1 + 10^((R_prob - R_user) / 400))
R'_user = R_user + K × (S - E_A)

Monaco IDE & Subprocess Sandbox

Full VS Code Monaco editor with Python 3 & JavaScript execution. Features process timeouts (5s limit), buffer caps, code auto-formatting, and starter code extraction.
